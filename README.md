#  Customer Churn Analysis using Python

##  Overview

This project focuses on analyzing **customer churn behavior** using simple data analysis and visualization techniques in Python. The main goal is to understand how many customers are leaving (churning) versus staying (retained), and to study customer subscription patterns.

The project uses **pandas** for handling data and **Matplotlib** for creating graphical representations.

---

##  Objective

* To analyze customer churn data in a simple way
* To compare churned and retained customers
* To study subscription duration trends
* To represent data visually using graphs

---

##  Dataset Description

The dataset used in this project contains:

* **Customer_ID** – Unique identifier for each customer
* **Subscription_Months** – Duration of customer subscription
* **Monthly_Charges** – Amount paid by customers
* **Churn** – Indicates whether the customer has left (Yes/No)

This dataset helps in understanding customer behavior and retention patterns.

---

##  Tools & Technologies Used

* **Python**
* **pandas** – for data manipulation
* **Matplotlib** – for data visualization

---

##  Features of the Project

### 1. Basic Data Analysis

The program performs simple analysis such as:

* Total number of customers
* Number of churned customers
* Average subscription duration

---

### 2. Data Visualization

####  Bar Chart (Churn vs Retained)

* Displays number of customers who stayed vs left
* Includes value labels for better understanding
* Helps in quick comparison

####  Line Chart (Subscription Trend)

* Shows variation in subscription months
* Includes markers for each data point
* Displays average line to indicate overall trend

---

##  Output Interpretation

* Higher number of “No” indicates good customer retention
* Customers with lower subscription months are more likely to churn
* The average line helps identify whether most customers stay above or below the average duration
